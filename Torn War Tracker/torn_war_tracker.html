About Torn War Tracker

What it does

Torn shows totals. This app shows who did what, when — slicing every ranked war into three phases so leadership can evaluate member performance with precision.

Tracks opponent top hitters, live score vs target, and auto-refreshes during active wars.

The three phases
Phase 1First 24h — target score is fixed. Main fighting window.
Phase 224h until net score crosses target. Decays 1%/hr.
Phase 3After target is crossed until war ends.
How to use
  1. Paste faction API key
  2. Click Load wars
  3. Select a war or use the active war banner
  4. Click Analyse
  5. Click Auto-detect — phase splits update automatically
API key selections needed
faction → rankedwars
faction → attacksfull
faction → revivesfull
faction → warfare
torn → rankedwarreport
Privacy

Runs 100% locally. Key and data stay on your machine. Only contacts api.torn.com. No servers, no tracking, no ads.
